**Emberkeep — The Last Hearth.** A tower-defence game about the last hearth in a frozen night. Frost wraiths crawl from three gates to snuff the fire; you are the Keeper. Build braziers, bellows mortars and frostward lanterns on the plots, earn embers from every banished wraith, and hold the hearth for ten waves — ending with the Frost King, who rises twice. Warmth is the hearth's health: if it reaches zero, the night wins.

- Three tower kinds, each with one upgrade tier, plus sell-back
- Four enemy kinds (shiverling, rimebound, wisp, the Frost King boss)
- Two abilities: Stoked Flare (screen nova) and Stoke Hearth (embers for warmth)
- Waves with banners, a build phase with an early-start bonus, score and best score
- WebAudio procedural sound, particles, snowfall, screen shake, pause, 2x speed

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network — the game is static files under `game/`.
